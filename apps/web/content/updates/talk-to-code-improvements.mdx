## Better transcription

Talk to Code lets you dictate a prompt instead of typing it on a phone keyboard. This release
rebuilds the transcription path end to end.

![Dictating a prompt to a coding agent with Talk to Code in the Vicoa mobile app](/images/updates/talk-to-code-improvements-1.png)

What changed:

- **More accurate transcription**, including code identifiers and file names
- **Speak naturally** — pauses and filler words no longer break the recording
- **Smoother, more reliable** voice sessions on slower connections

Dictating a paragraph of context to Claude Code while walking is now realistic. Update to the
latest version of the app and give it a try.
