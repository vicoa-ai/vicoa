## A catalog of agents

Open **Settings → Providers → More agents** for a catalog of 33 agents that speak ACP (the
Agent Client Protocol): Cline, Factory Droid, Qwen Code, Amp, goose, Junie, Kilo, Kiro,
Devin and more. **Add** puts one on the machine you pick, and **Check** launches it and
tells you whether it works, which models it offers, or exactly why it failed.

Prefer the terminal? `vicoa provider catalog`, `vicoa provider add <id>` and
`vicoa provider check <id>` do the same.

ACP agents also show more of what they're doing: tool calls as they start, the agent's
plan as a checklist, live token usage, and the agent's own slash commands in the message
box. Agents you add show up in the mobile app's agent picker too.

## Antigravity and Pi

Google's Antigravity CLI (`agy` 1.1.15 or newer) is in the agent picker, with its live
model list and three permission modes you can switch mid-session. Pi and Oh My Pi are
there too.

## Codex and Copilot usage

The message box now shows your Codex and GitHub Copilot usage limits, the same meter
Claude sessions already had.

## Save agent presets

In **Settings → Agents**, save a provider, model, config and system prompt under one name.
Pick it from **My agents** when you start a session, or use it in an automation.

See every supported agent on the [coding agents page](/coding-agents).
