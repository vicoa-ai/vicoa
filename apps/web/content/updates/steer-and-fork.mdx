## Steer: don't wait for the turn to end

A message you send while the agent is working waits in the queue until the turn ends. Now
each queued message has a **Steer** button. The agent picks the message up at its next
safe point, mid-turn, so you can correct course before it goes further down the wrong path.

Steer works with Claude Code, Codex, Pi and Oh My Pi. A message the agent can't take
mid-turn goes back to the queue.

## Fork: try another direction

Fork a session from any agent turn. The conversation up to that point carries into a new
session on the same machine, folder and agent, and the original stays as it was. The
fork carries the conversation itself and leaves tool output out, so the new agent re-reads
what it needs.

On mobile, the carried conversation sits as a chip above the message box, so you can read
it or remove it before you send.

Both work on the web, in the desktop app, and in the latest iOS and Android apps.
