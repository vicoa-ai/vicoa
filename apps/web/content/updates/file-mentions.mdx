## Reference files directly in your prompts

Type `@` in the chat and Vicoa fuzzy-searches your project files, exactly like native Claude Code
and Codex do in the terminal.

![Referencing a project file with an @ mention in the Vicoa chat](/images/updates/file-mentions-1.png)

Point your agent at the right file without describing where it lives or pasting a path from
memory. Available on both web and mobile — update to the latest Vicoa CLI and app to use it.
