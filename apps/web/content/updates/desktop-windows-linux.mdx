## Every desktop platform

When we launched [Vicoa for Mac](/updates/mac-desktop-app), Windows and Linux were on the
way. They're here: the desktop app now runs on all three.

- **Windows**: a 64-bit installer for Windows 10 and 11
- **Linux**: a 64-bit AppImage. Mark it executable (`chmod +x`) and run it, no install step
- **macOS**: separate Apple Silicon and Intel builds

## At home on Linux

On Linux the app draws its own title bar, so the window no longer wears two title bars and
a menu bar. Alt still shows the native menu, and if you'd rather your desktop draw the
frame, switch to **Settings → Appearance → Window → Title bar → System**.

## Get started

1. [Download Vicoa](/download) for your platform
2. Install it and sign in
3. The app finds the coding agents you already have and connects them
