## The whole stack, on GitHub

Vicoa is now open source under AGPLv3: the CLI and daemon, the backend, the web
dashboard, the desktop app and the mobile app, all in
[one repository](https://github.com/vicoa-ai/vicoa).

It isn't a stripped-down community edition. It's the same code that runs vicoa.ai. If you
use the hosted app, nothing changes: same app, same account.

## Self-host it

Run the backend, the realtime server and the web dashboard on your own infrastructure
with Docker, and point your machines at it instead of vicoa.ai. A self-hosted install has
no plans and no limits; only billing and the marketing site stay out of the repo.

The [self-hosting guide](https://github.com/vicoa-ai/vicoa/blob/main/SELF_HOSTING.md)
walks through it.

## Contribute

Found a bug, or want your favourite agent supported? Open an issue or a pull request.
[CONTRIBUTING.md](https://github.com/vicoa-ai/vicoa/blob/main/CONTRIBUTING.md) has the
setup, and a star on the repo helps more people find it.
