## # reaches into Vicoa

`@` pulls your files into a prompt. `#` does the same for the rest of your workspace: a
running session, a task, or an automation.

Type `#` in the message box and start typing a name, or press `#` on its own to see the
most recent of each.

```
continue from #zesty-quartz, it left the migration half applied
```

## What the agent gets

The token stays in your message, and Vicoa attaches a short block with the details: a
task's status, priority and description; a session's agent, folder and worktree; an
automation's schedule and prompt. Each block ends with the `vicoa` command for the full
record, so the agent can dig further on its own instead of asking you to paste more.

## Referencing a task files the session

Reference a task and the session joins that task's **Sessions** list, and the task moves
to *In Progress*. Changed your mind? Delete the token and the reference goes with it.

Available in the web app and the desktop app. Read more in the
[features guide](/docs/vicoa-features#reference-sessions-tasks-and-automations).
