# Mobile App

### v1.7.18
18 November, 2026
- Home and Tasks open the way you left them. Home remembers the groups you folded (Project, Status and Pinned) and its agent and date filters, and Tasks remembers its folded status sections, project filter and display options
- Branch icons on Home session cards and the Worktrees page take the color of the branch's pull request: open green, merged purple, closed red, draft grey. The worktree sheet shows the pull request with its checks and an "Open on GitHub" button
- The Send button turns into a Stop button while the agent is working and the message box is empty. Typing, an attachment or an annotation brings Send back, so you can still queue a follow-up. The separate stop button next to the folder icon is gone
- Send a message to a closed or stopped session to resume it: the box stays open and sending relaunches the session on its computer. Only the owner can resume, and the box stays locked when the computer is offline
- A worktree on a detached HEAD shows its short commit with a "detached" tag, and a worktree in the middle of a rebase keeps its branch name with a "rebasing" tag
- The answer to a Claude question stays in the transcript instead of disappearing when the session was active
- A push for a task assigned to you, a question an agent asks you on a task, or an `@` mention of you on a task opens that task
- Android: the welcome card shows Vicoa's own mark and name

### v1.7.17
14 November, 2026
- Select text in an agent chat to get Add to chat and Continue in new session next to Copy, on message text, code blocks, diffs and terminal output. Add to chat keeps the passage as an annotation pill with an optional comment that goes out with your message; Continue in new session carries the selection to a new session, on the same machine, folder and agent when the session is yours
- Show "Task created" after you create a task, unfold the status section it lands in if it was folded, and scroll the Tasks list to it
- Sending a message no longer costs a credit, and the no-credit sheet no longer appears when you send
- When your plan's automation limit is reached, creating an automation shows the reason from the server and opens the Upgrade dialog
- Draw the iOS launch screen in the splash's dark color, so a cold start no longer flashes white in dark mode

### v1.7.16
29 October, 2026
- Ask an Apple sign-in with no email address for one before the app opens; some Apple IDs registered by phone number give none, and the app needs it to work
- Show AskUserQuestion option previews, drafts, mockups or snippets, in one pane beside the options
- Add Claude Sonnet 5.5 to the model picker and drop duplicate 1M-context model options
- Mark a reviewed session Unread again from Home or the chat menu, so its blue dot comes back
- Keep a project on Home even when none of its sessions is open, and start a session right from its empty row

### v1.7.15
11 October, 2026
- Pick the session an automation runs in: the editor's new Runs in row opens a picker with "New session each run" (the default), your recent sessions and a search across all of them, and a picked session brings its own machine, folder and agent
- Task ids like `VIC-42` show on task cards, in the task sheet, on sub-tasks and in search, and search finds a task by its id once you type the dash (`vic-4`)
- Filter automations by project, from a new Project section in the Automations filter
- Home's project groups work like the web sidebar: each group leads with the project's icon, two projects with the same name stay separate, sessions of an archived project leave Home (pinned ones stay), and a project named "Done" or "Today" keeps its name
- A session whose delete fails comes back where it was, instead of staying hidden until the app restarts
- Error messages stay up for 3 seconds so you can read them, and the "Welcome to Vicoa" and "Get started" titles are readable in light mode
- The search field no longer autocorrects what you type, so an id like `lig-1` stays as typed

### v1.7.14
7 October, 2026
- Type `#` in the chat composer or the new session prompt, or pick "Reference a session or task" from the "+" menu, to point the agent at one of your sessions, tasks or automations; it goes out with your message as context, and referencing a task also files the session under that task
- Pick a saved agent in an automation's Agent list, with your team's agents under their team; each run uses that agent's own config, so Model, Effort and Permission step aside, and Run now uses its instructions too
- Automations are listed in the order you drag them into on the web or desktop
- The project picker leaves out projects shared with you that you have not added to your sidebar, since a session started there would not be filed under them

### v1.7.13
3 October, 2026
- Open a video in the Files tab and it plays, with download progress, a scrubbable progress bar, skip 15 seconds and playback speed; it works for videos up to 100 MB, and the machine needs Vicoa CLI v1.9.8 or later (an older one shows a hint to update it)
- The "Vicoa is open source" card no longer sits above your sessions on the home screen; the repo is still a tap away in Profile, Help & Feedback and Usage & Credits

### v1.7.12
29 September, 2026
- Remove a worktree even while a session is running in it: its running sessions are archived first, and the branch is kept so your commits stay safe
- Fix removing a worktree failing when the worktree list was opened from inside that worktree; an error there now stays on screen long enough to read
- Claude Opus 5.5 joins the model picker
- Auto mode is offered for every Claude model, including older ones like Opus 4.6
- Fix the home screen stopping short of older sessions while a status filter was on; it now loads 50 at a time and keeps going to the end

### v1.7.11
24 September, 2026
- Share a session with a live link, not just a copy of it — one tap creates the link, copies it and opens the share sheet, and it keeps updating as the session runs until you revoke it; who can open it, when it expires and whether your name and branch names show are in Link settings, and the old pick-the-messages export is still there under Export
- Fork a session from any agent turn — the conversation so far rides along as a chip above the composer that you can read or remove, with the machine, folder and agent already set from the session you forked
- Steer a queued message into the agent's running turn instead of waiting for the turn to end, on the agents that can take one mid-turn (Claude Code, Codex, Pi, Oh My Pi)
- A collapsed tool run names the files it edited — tap one to open it in the file viewer, rather than walking down the Files tab to find it
- A stopped or archived session's composer now says where to pick it back up (Resume, in the top-right menu), and the agent-stopped and machine-offline hints are translated instead of showing English in a Chinese app

### v1.7.10

- New agents: Antigravity, Pi and Oh My Pi, plus any ACP agent added from the catalog on a machine; Claude Opus 5 in the model list

- The "working…" indicator no longer shifts the conversation at the start and end of a turn
- Automations are saved in your device's real timezone
- Fix the awaiting-input dot lingering after you leave a session
