# Mobile App

### v1.7.8
22 August, 2026
- Show a blue dot on the session list for sessions awaiting your input
- Fix empty chat when opening an agent session from a notification
- Fix links in messages that couldn't be selected or copied

### v1.7.7
17 August, 2026
- Add workspace search to quickly find sessions and tasks
- Add a getting-started checklist to the home screen that hides once you're set up
- Add minutely and daily-window scheduling to Automations
- Improve slash commands and file mentions on the Tasks and Automations pages, and reveal a file mention's full path on long-press
- Show the absolute reset time and on-demand Claude rate limits in the usage indicator
- Add per-tool icons to the agent chat transcript and tighten spacing between blocks
- Point new users to the desktop app during onboarding, and add empty-state CTAs and a connect-machine guard to Tasks and Automations
- Fix the automation editor showing an online machine as offline
- Fix a muddy light-mode background on the floating tab bar

### v1.7.6
6 August, 2026
- Add an Automations page to schedule recurring agent runs
- Add a navigation bar to switch between sections
- Improve the Tasks experience
- Keep your machine, directory, worktree, and task selections when returning to start a new session
- Polish AskUserQuestion and sub-agent spacing in chat
- Refresh the Vicoa logo
- Require iOS 15 or later

### v1.7.5
23 July, 2026
- Add Tasks: support view task list and create/edit tasks
- Start a session directly from a task, seeding your first prompt
- Support attaching files
- Support resuming a stopped session from the chat options menu
- Show context-window and rate-limit usage
- Stage queued messages in a bar above the chat input, with a cancel action
- Group sub-agent activity under a collapsible header in chat
- Show session liveness

### v1.7.4
18 July, 2026
- Rename session "Closed" status to "Archived"
- Compact tool-use display: ellipsize long headers, fix chevron position and expand flicker
- Add Sonnet 5 and Claude Fable 5 to the agent catalog

### v1.7.3
11 July, 2026
- Support sending and viewing image attachments in agent chat
- Rename add-to-chat image entries to "Photo" and "Camera"
- Improve the empty-worktree state with a branch icon and clearer copy
- Re-register push notifications on resume so late-enabled notifications work

### v1.7.2
