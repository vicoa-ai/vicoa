# Desktop App

### v0.1.34
3 October, 2026
- Bundle Vicoa CLI daemon [v1.9.8](/docs/changelog/vicoa-cli#v198)
- A session shared with you opens in the normal session page and updates live: an editor prompts from the same composer, a viewer reads along
- Sessions more than one person wrote in show who is in them, with faces beside the title, on the sidebar row and over each person's prompts; other people's sessions in a project you own sit under a collapsed Team row at the end of the project
- Move a project into a team, or back to your own space, from its settings; the team page lists the team's projects, agents and labels, and anyone on the team can run its agents
- Teams get a free Viewer role that reads and comments without taking a seat, and seats are bought and changed on their own page, linked from Billing and the team page
- Play a video from the Files tab instead of getting "No preview available"; it streams and seeks without downloading the whole file first
- A task's page lists its sub-tasks with done/total progress and an input to add more, and a sub-task links back to its parent
- The session sidebar starts grouped by project on a fresh install; a grouping you already picked is kept
- Fix the desktop app and the `vicoa` CLI fighting over the sign-in: a desktop sign-in after `vicoa --auth` now takes effect, and `vicoa --auth` no longer signs the app out
- Fix the transcript bouncing at the bottom as you scroll

### v0.1.33
29 September, 2026
- Bundle Vicoa CLI daemon [v1.9.7](/docs/changelog/vicoa-cli#v197)
- Share a project or a session with specific people, not only by link: the Share dialog has a new People tab where you invite by email or pick a team, give a role (Viewer, Commenter, Editor or Admin) and choose whether they see the tasks, the sessions or both
- Settings → Teams lets you create a team and invite people by email or with an invite link; an invitation shows up in the invitee's account menu with Join and Decline
- Anything shared with you appears under Shared with me in the sidebar, and a shared session opens read-only and refreshes on its own
- With a project selected, the Tasks page shows who it is shared with next to Share
- A "+" on the sidebar's Workspaces header starts a new session, and an empty sidebar now tells you how to get going
- Join Discord straight from the account menu
- Auto mode is offered for every Claude model, including older ones like Opus 4.6
- Fix the transcript flickering between two scroll positions when a long message or an agent's question sat near the edge of the view
- Fix deleting a clean worktree failing with a submodule error in a repo whose submodules were never checked out there

### v0.1.32
26 September, 2026
- Bundle Vicoa CLI daemon [v1.9.6](/docs/changelog/vicoa-cli#v196)
- Type `#` in the composer to point the agent at another Vicoa thing — a live session, a task or an automation — and it goes out with your message as context; referencing a task also files the session under that task, and deleting the token drops the attachment
- Hide the sidebar rows you don't use: New Session, Tasks, Automations, Agents, Skills and Search each get a switch under Settings → Appearance → Sidebar, and a hidden row's page stays reachable by URL
- Cmd/Ctrl+E toggles focus mode in both directions, replacing a shortcut that typed a stray backtick into the file you were editing instead of firing
- Delete an archived session straight from its sidebar row — the trash icon takes the slot Archive vacates once a session is archived
- Claude Opus 5.5 joins the model picker

### v0.1.31
24 September, 2026
- Bundle Vicoa CLI daemon [v1.9.5](/docs/changelog/vicoa-cli#v195)
- Linux gets the app's own title bar, so the window no longer wears two of them plus Chromium's menu bar — the logo, the application-menu button and the min/max/close cluster are drawn by the app, Alt still reveals the native menu, and Settings -> Appearance -> Window -> Title bar -> System hands the frame back to your desktop if you would rather it drew its own
- Edit a markdown table in the grid instead of in its pipes — type straight into a cell, Tab and the arrows walk between cells and rows, your hand-aligned spacing survives, and Escape drops back into the markdown on the same character for the things a grid cannot express
- The markdown editor follows links on Cmd/Ctrl+click, with the link underlining itself while the key is held; pasting from a web page now keeps its links, headings and tables as markdown rather than flattening them to plain text
- Front matter at the top of a markdown file reads as a quiet metadata block instead of a stray divider, a click on a table lands in the cell you clicked, and the editor uses the panel's full width rather than stopping mid-pane
- Sessions live at their own address now — `/dashboard/sessions/<id>`, with `/dashboard/sessions/new` for a new one — leaving `/dashboard/agents` to the saved agent presets it was named for; old links, bookmarks and notifications keep working
- "Open" on a session card in a task's timeline opens that session, rather than dropping you on the dashboard's "start a session" home
- A share link's "Settings" edits the link you already sent — audience, expiry, what it shows, what it covers — with "New link" still there for when a fresh URL is the point
- Onboarding shows every built-in agent on the intro strip, and the agent-scan list scrolls with the app's own scrollbar
- Fix a session that is still running being marked finished after seven idle days, which could end a session part-way through a long rate-limit wait
- Fix OpenCode reading as not installed when it was installed with its own installer

### v0.1.30
22 September, 2026
- Bundle Vicoa CLI daemon [v1.9.4](/docs/changelog/vicoa-cli#v194)
- Diffs now box the words that changed, the way an editor does — in the Changes tab and in the editable side-by-side view, layered over syntax highlighting rather than replacing it, with a re-wrapped paragraph pairing up properly instead of reading as a full rewrite
- Fix a large file with edits scattered through it rendering as one solid red block over one solid green block, with every untouched line in between counted as changed
- Fix a share link that opted into showing your name drawing an initials disc instead of your picture, and the same for assignees, comment authors and reactors on a shared board

### v0.1.29
21 September, 2026
- Bundle Vicoa CLI daemon [v1.9.3](/docs/changelog/vicoa-cli#v193)
- Project settings live in one place — Settings → your project has General (display, linked folders per machine, archive and delete), Git & Worktree (setup hooks, with a machine picker when several are linked) and Tasks (the task key prefix, settable before the first task); the Tasks page gear now takes you there
- Labels get their own Settings → Tasks tab — one vocabulary across all your projects
- Settings lists every project, including ones without a session, with archived projects under a collapsed group so Unarchive and Delete stay reachable
- Delete worktree no longer makes you wait — the dialog closes on Confirm, the worktree's sessions are archived together and their terminals closed, and a failure reopens the dialog with the error and a Retry button
- Collapsed tool runs and sub-agents show one chip per edited file — name only, full path on hover, wrapping whole rather than clipping — and clicking a chip opens the file in the Files panel; up to 8 before "+N more"
- OpenCode edits and commands are carded like Claude Code's, with the path and diff on one card
- A session moved with `vicoa session update --worktree` jumps to its new sidebar group immediately, no reload needed
- Fix search showing "Search failed" for any query that matched a task under "No project"

### v0.1.28
20 September, 2026
- Bundle Vicoa CLI daemon [v1.9.2](/docs/changelog/vicoa-cli#v192)
- Share a session or a project with a read-only link from the session header, the sidebar ⋯ menu or the Tasks header — public or signed-in only, with expiry and a choice of tasks and/or sessions
- New session picks a project, not a path — your projects on the chosen machine come first, and a subfolder carries into a new worktree

- Fix file links with a space or non-ASCII character in the path failing to open, copy or reveal

### v0.1.27
16 September, 2026
- Bundle Vicoa CLI daemon [v1.9.1](/docs/changelog/vicoa-cli#v191)
- Antigravity joins the agent picker — Google's Antigravity CLI (agy 1.1.15 or newer) with its live model list and three permission modes (read only, accept edits, bypass), switchable from the gear mid-session
- See your Codex and GitHub Copilot usage in the composer, the same meter Claude sessions already had; catalog-added agents now get a real model and permission-mode picker on the new-session page, probed once per machine
- Branch icons in the sidebar are coloured by pull-request state — green open, purple merged, red closed, grey draft or none — and hovering one shows the title, check status and buttons to open or copy the PR link
- Name a new worktree from the picker — the name becomes the branch and the folder, is checked as you type, and a taken name suggests the first free suffix instead of silently picking another
- Open a file with the OS default app or reveal it in Finder / File Explorer / File Manager straight from the "No preview available" card and the Open in ▾ menu — and spreadsheets, Word and PowerPoint documents, PDFs, archives, audio, video and fonts now get their own icons in the file tree, tabs and search palette
- Start a session from a task's detail page — the same flow as the board's context menu, including the sub-task picker
- The Changes tab's Refresh button now refreshes the history pane too, and Files and Changes refresh on their own when the session's agent finishes a turn
- A machine that goes offline with editor tabs open no longer keeps firing failed file checks — the check backs off until the machine is back
- Fix a session failing to start with "Headless Claude encountered a fatal error" when the server is slow, and a failed start now says why instead of opening an empty session

### v0.1.26
13 September, 2026
- Bundle Vicoa CLI daemon [v1.9.0](/docs/changelog/vicoa-cli#v190)
- Add an agent in one click — Settings → Providers now lists a catalog of 33 ACP agents (Cline, Factory Droid, Qwen Code, Amp, goose, Junie, Kilo and more) with their logos; Add puts one on the machine you pick, and Check launches it and tells you whether it works, which models it offers, or exactly why it failed
- Agents added by hand in `~/.vicoa/config.json` appear in the agent picker too, with a readable label and icon
- ACP agents (Cursor, Gemini CLI, Copilot, Kimi and the catalog ones) now show tool calls as they start, the agent's plan as a checklist, live token usage, and the agent's own slash commands in the composer
- Select chat text reliably — drags no longer die about one time in fifteen on a Retina trackpad, a drag that leaves a table stays on the row you are level with, a selection no longer spreads backwards while the transcript updates, and tool rows, thinking cards and links are selectable too
- Ctrl+Tab and the other Ctrl shortcuts no longer also type into the terminal — switching tabs used to send a Tab to the shell (and on Linux, Ctrl+W closed the tab and deleted a word)
- Worktree groups in the sidebar follow the folder, so checking out a new branch inside a worktree no longer splits it into two groups; a worktree removed outside the app is shown struck through, and Delete worktree cleans it up instead of failing with `not_a_repo`
- Fix a just-created session appearing as a second copy of its project in the sidebar until the next reload
- Fix Settings → Providers making the page scroll sideways when one agent's description was long
