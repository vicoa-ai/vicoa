# Desktop App

### v0.1.21
3 September, 2026
- Bundle Vicoa CLI daemon [v1.7.17](/docs/changelog/vicoa-cli#v1717)
- Add a real light theme with a systematic, token-driven design and an Appearance tab in Settings to switch themes (dark is unchanged)
- Add a declarative plugin system — install and manage Tier 1 plugins (custom themes, sidebar links, composer actions) from Settings, with a first-load trust gate
- Unify project identity across the sidebar, Tasks, and Settings — auto-created projects with image, emoji, or generated icons (seeded from your git remote), cross-device archive, and stale-project auto-archiving
- Show model reasoning as a collapsible Thinking card, and render agent tool calls as tidy collapsible cards
- Add Opus 5 to the new-session picker and default supported Claude models to auto mode
- Restore a session's model, effort, and permission mode when you resume it, so an auto-mode session no longer comes back as default

### v0.1.20
2 September, 2026
- Bundle Vicoa CLI daemon [v1.7.16](/docs/changelog/vicoa-cli#v1716)
- Run per-worktree setup and teardown scripts when you open or remove a worktree session, with the setup output shown live in the session terminal

### v0.1.19
31 August, 2026
- Bundle Vicoa CLI daemon [v1.7.15](/docs/changelog/vicoa-cli#v1715)
- Group sessions under their project in the sidebar and keep worktree grouping stable, so sessions no longer jump to the wrong repo
- Live-update the onboarding checklist as you complete steps, without a page refresh
- Keep your place when a new session opens after you've navigated away, instead of stealing focus

### v0.1.18
24 August, 2026
- Bundle Vicoa CLI daemon [v1.7.12](/docs/changelog/vicoa-cli#v1712)
- Show why a session failed to start or went silent directly in the composer, instead of a generic "not accepting input"
- Esc unfocuses the chat composer instead of interrupting a running turn
- Fix the message bounce when sending a message mid-turn
- Fix task-list markdown rendering in chat so long items no longer shatter into columns
- Auto-focus the terminal on open, tab-switch, and cycle

### v0.1.17
20 August, 2026
- Bundle Vicoa CLI daemon [v1.7.11](/docs/changelog/vicoa-cli#v1711)
- Add a Skills tab to view, install (from a git URL), and uninstall per-machine agent skills, with per-agent tabs, search, and a skill detail dialog
- Auto-continue rate-limited sessions once their limit window resets

### v0.1.16
18 August, 2026
- Bundle Vicoa CLI daemon [v1.7.10](/docs/changelog/vicoa-cli#v1710)

- Persist Files/Changes panel view toggles as preferences
- Show the absolute reset time in the usage indicator
- Show repo-local skills in new-session and mention menus
- Kill terminals when a session is closed
- Fix the side-by-side diff scrollbar reverting to the browser default and match CodeMirror scrollbars to the site style
- Use ⌥` for the peek-chat toggle

### v0.1.15
