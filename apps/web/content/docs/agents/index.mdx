# Agents

AI coding agents supported in Vicoa:

- [Claude Code](/docs/agents/claude-code)
- [Codex](/docs/agents/codex)
- [OpenCode](/docs/agents/opencode)
- [More coding agents](/docs/agents/more-coding-agents) — Gemini, Cursor, Copilot, Kimi, Hermes, Pi, Oh My Pi, and Antigravity
- [Custom agents](/docs/agents/custom-agents) — 30+ more agents supported via ACP (Cline, goose, Kiro, Qwen Code, TRAE, and others), or any other ACP agent with your own command

You can switch between Claude Code, Codex, and OpenCode at any time with commands:

```bash
# Start with Claude Code (default)
vicoa

# Jump into Codex for a targeted fix
vicoa codex

# Try OpenCode for mobile-first development
vicoa opencode

# Back to Claude Code
vicoa
```

Gemini, Cursor, Copilot, Kimi, Hermes, Pi, Oh My Pi, and Antigravity are launched directly from a new session in the web dashboard or mobile app — see [more coding agents](/docs/agents/more-coding-agents).
