# Agents

AI coding agents supported in Vicoa:

- [Claude Code](/docs/agents/claude-code)
- [Codex](/docs/agents/codex)
- [OpenCode](/docs/agents/opencode)
- [More coding agents](/docs/agents/more-coding-agents) — Gemini, Cursor, Copilot, Kimi, and Hermes

You can switch between Claude Code, Codex, and OpenCode at any time with commands:

```bash
# Start with Claude Code (default)
vicoa

# Jump into Codex for a targeted fix
vicoa codex

# Try OpenCode for mobile-first development
vicoa opencode

# Back to Claude Code
vicoa
```

Gemini, Cursor, Copilot, Kimi, and Hermes are launched directly from a new session in the web dashboard or mobile app — see [more coding agents](/docs/agents/more-coding-agents).
