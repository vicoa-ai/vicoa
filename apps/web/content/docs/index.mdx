# Introduction to Vicoa

Vicoa lets you run a team of coding agents (Claude Code, Codex, and OpenCode) anywhere, on any device. Start coding on your laptop, switch easily to mobile or web, get alerts when your AI agent needs input, and approve changes with one tap.


## Features

- **Cross-platform vibe coding**: Start on desktop, continue on mobile or tablet
- **Mobile-first design**: Full coding experience on phones and tablets
- **Smart notifications**: Get alerts when your AI agent requires permission or needs input
- **Original vibe coding experience**: Vibe coding like normal Claude Code, Codex, and OpenCode sessions
- **Seamless workflow**: Pick up exactly where you left off


## Quick Start

Get up and running with Vicoa in minutes:

1. **Install** Vicoa CLI: `npm i -g @vicoa/cli && vicoa`
2. **Sign up** for a Vicoa account
3. **Download** the mobile app or use the web interface
4. **Start coding** anywhere you go
