# Claude Code vs. Codex in Vicoa
Learn how Vicoa uses Claude Code by default, how to switch to Codex, and the exact CLI commands to manage both agents.

Vicoa supports both Claude Code and Codex. **Claude Code** is the default agent so the CLI feels familiar right out of the box. **Codex** is also integrated: start it from the Vicoa app or with `vicoa session start`.

This guide answers the common questions we hear about swapping between Claude Code and Codex and highlights the commands you’ll use most.

## Default Agent Behaviour

Out of the box, `vicoa` starts **Claude Code** so you can get productive immediately. If you ever changed the default in the past, Vicoa keeps that preference until you update it again. If you had made Codex the default, plain `vicoa` now prints how to start Codex instead; run `vicoa --set-default claude` to make it start Claude Code again.

## Start a Codex Session

Codex runs through the Vicoa daemon rather than in your terminal. Click **New Session** in the app and choose Codex, or start one from your project directory:

```bash
vicoa session start --agent codex --dir .
```

The session shows up in the app, where you can carry on. Your default is unchanged, so `vicoa` with no flags still starts Claude Code. `vicoa codex` and `vicoa --agent codex` are no longer supported; see [Codex](/docs/agents/codex) for details.

## Restore Claude Code as the Default

To switch back to Claude Code as default, run:

```bash
vicoa --set-default claude
```

## Frequently Asked Questions

### Can I keep Claude Code and Codex available at the same time?

Yes. Keep Claude Code as your terminal default, then start Codex whenever the task demands it. For example:

```bash
# default is Claude Code
vicoa

# jump into Codex for a targeted fix (the session opens in the app)
vicoa session start --agent codex --dir .

# hop back to Claude Code without changing the default
vicoa
```

### Do I need to reauthenticate after switching agents?

No. Agent selection happens client-side inside the CLI. As long as your Vicoa session is active, both Claude Code and Codex respect the same authentication state.

### When should I prefer Claude Code vs. Codex?

Both Claude Code and Codex are powerful tools, and they are both improving and evolving. The choice between them depends on your specific projects.  

### Do I need to do anything on mobile app or web to switch between Claude Code and Codex?

No. Vicoa syncs both agents in similar way. We aim to provide the best experience for both agents seamlessly with customized formatting. If there are design or formatting preferences you prefer, please let us know at hi@vicoa.ai.

## Tip: Keep Both Agents Handy

Many developers and teams use both Claude Code and Codex at the same time. Start Codex from the app or with `vicoa session start --agent codex` on demand, while `vicoa` keeps starting Claude Code in your terminal.
