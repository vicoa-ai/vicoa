# Symbols Nerd Font Mono — license & provenance

`SymbolsNerdFontMono-Regular.woff2` is the **Symbols-Only** Nerd Font from the
[ryanoasis/nerd-fonts](https://github.com/ryanoasis/nerd-fonts) project
(release **v3.4.0**, asset `NerdFontsSymbolsOnly`). It contains ONLY the Nerd
Font symbol glyph ranges (Powerline, Font Awesome, Devicons, Octicons,
Material Design Icons, Weather, Seti-UI, …) and no Latin/CJK text glyphs, so it
is used purely as a fallback for the terminal's normal monospace text font.

- **Nerd Fonts patch tooling / this symbols set:** MIT License,
  Copyright (c) 2014 Ryan L McIntyre (see below).
- Individual upstream icon sets carried by Nerd Fonts retain their own
  permissive licenses (MIT / OFL / Apache-2.0). Full details:
  https://github.com/ryanoasis/nerd-fonts#font-patcher and
  https://github.com/ryanoasis/nerd-fonts/blob/master/LICENSE

Conversion: the upstream `SymbolsNerdFontMono-Regular.ttf` (2.5 MB) was
converted losslessly to `.woff2` (1.15 MB) with fontTools; all 10,410 glyphs
are preserved.
